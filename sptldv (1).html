Tujuan Pembelajaran

Tujuan 1

Peserta didik mampu menentukan dan menggambar daerah penyelesaian sistem pertidaksamaan linear dua variabel pada bidang koordinat dengan benar.

Tujuan 2

Peserta didik mampu memodelkan masalah kontekstual dunia kerja, seperti keterbatasan bahan, waktu, dan biaya produksi, ke dalam SPTLDV serta menafsirkan daerah penyelesaian dan nilai optimum sederhana untuk mengambil keputusan.

Materi

1. Pertidaksamaan linear dua variabel

Bentuk umum: ax + by ≤ c, dengan tanda lain yang mungkin: <, ≥, >. Variabel x dan y masing-masing berpangkat satu.

Contoh: 2x + 3y ≤ 12. Pasangan (x, y) yang membuat pernyataan itu benar disebut penyelesaian. Semua penyelesaiannya membentuk daerah penyelesaian pada bidang koordinat.

2. Langkah menggambar daerah penyelesaian

  1. Ubah tanda menjadi sama dengan untuk mendapat garis batas. Contoh: 2x + 3y = 12.
  2. Cari titik potong sumbu. Jika x = 0 maka y = 4, titik (0, 4). Jika y = 0 maka x = 6, titik (6, 0).
  3. Gambar garis. Garis penuh untuk ≤ dan ≥. Garis putus-putus untuk < dan >.
  4. Uji titik, biasanya (0, 0). Substitusi: 2(0) + 3(0) = 0 ≤ 12 benar, maka daerah yang memuat (0, 0) diarsir.
Jika garis melewati titik (0, 0), jangan uji (0, 0). Pakai titik lain, misalnya (1, 0) atau (0, 1).

3. Sistem pertidaksamaan

Sistem adalah beberapa pertidaksamaan yang berlaku bersamaan. Daerah penyelesaian sistem adalah irisan (bagian yang diarsir oleh semua pertidaksamaan).

Pada soal produksi, hampir selalu ada syarat x ≥ 0 dan y ≥ 0 karena banyak barang tidak boleh negatif. Daerahnya berada di kuadran I.

4. Coba sendiri: penjelajah daerah penyelesaian

Ubah angka, lalu klik atau sentuh bidang untuk menguji sebuah titik. Syarat x ≥ 0 dan y ≥ 0 sudah termasuk.

Klik sebuah titik pada bidang.

5. Memodelkan masalah dunia kerja

Contoh. Bengkel las membuat pagar (x unit) dan teralis (y unit). Pagar butuh 2 jam kerja dan teralis 1 jam. Waktu kerja tersedia paling banyak 40 jam. Bahan besi: pagar 3 batang, teralis 4 batang, tersedia paling banyak 90 batang.

Pagar (x)Teralis (y)Tersedia
Waktu (jam)21≤ 40
Besi (batang)34≤ 90

Model: 2x + y ≤ 40, 3x + 4y ≤ 90, x ≥ 0, y ≥ 0.

Kata kunci: "paling banyak" atau "tidak lebih dari" berarti ≤. "Paling sedikit" atau "minimal" berarti ≥.

6. Nilai optimum sederhana

Jika keuntungan Z = 50x + 40y (ribu rupiah), nilai maksimum atau minimum Z terjadi di salah satu titik sudut daerah penyelesaian.

  1. Gambar daerah penyelesaian dan tentukan titik sudutnya.
  2. Substitusikan setiap titik sudut ke Z.
  3. Pilih nilai terbesar (maksimum) atau terkecil (minimum).
  4. Tafsirkan dalam kalimat: berapa unit tiap produk dan berapa hasilnya.

Contoh. Daerah: x + y ≤ 8, x ≤ 5, x ≥ 0, y ≥ 0. Titik sudut: (0,0), (5,0), (5,3), (0,8). Dengan Z = 50x + 40y: 0; 250; 370; 320. Maksimum Z = 370 di (5, 3). Keputusan: produksi 5 pagar dan 3 teralis, untung Rp370.000.
